# Privacy Policy

Last updated: 14 November 2026

This privacy policy applies to "Personal Captions and Upload Script", a private personal tool used by one person, Ivan Korjavin, to manage videos and subtitles on his own YouTube channel (https://www.youtube.com/@clever_taussig). The tool is not offered to the public and has no other users.

## What the tool does

The tool uses the YouTube Data API v3 to upload videos, create and edit captions (subtitles), and update video metadata on the channel owned by the developer. It is run only by the developer, with the developer's own Google account.

## Data we access and store

The tool accesses only the developer's own YouTube channel data through the YouTube API Services. It does not collect, store, sell, share or disclose data of any other person. Authorization tokens are stored locally on the developer's own computer and are never transmitted to third parties.

## YouTube API Services

The tool uses YouTube API Services. By using it, the developer is bound by the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy). Access to the tool's data can be revoked at any time in the Google security settings: https://security.google.com/settings/security/permissions
